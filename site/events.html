Équilibrée : marges plus courtes (30 min minimum entre trains dans la même gare), mais davantage de choix. Aucun réglage ne garantit une correspondance.

Option facultative : les propositions hors marge demandée apparaissent avec « ⚠ ». Le temps entre gare et lieu reste à valider par l’organisateur.

04

Choix des horaires

Vos voyageurs choisiront leurs horaires sur une page Transbora, sans inscription.

Mode essai : aucun code à saisir. Choisissez les liens à créer, puis copiez-les pour les envoyer aux voyageurs.

1. Créer les liens à envoyer

👥

Un lien pour tout le groupe

Une seule page contenant les choix de tous les voyageurs, à transmettre uniquement à la personne responsable du groupe.

👤

Un lien par voyageur

Chaque personne reçoit uniquement ses propres propositions et confirme ses trajets.

Création terminée

2. Envoyer les liens aux voyageurs

Appuyez sur Copier puis collez le lien dans WhatsApp, un SMS ou un e-mail. Le voyageur n’a pas de code à saisir.

Vous pouvez corriger votre choix sans refaire la recherche. Les anciens liens seront désactivés, mais les réponses déjà reçues seront conservées.
