Mode d’emploi

Créez un événement, ajoutez les voyageurs, cherchez leurs horaires, puis exportez les Excel.

1 · Événement

Renseignez le nom, la destination et les horaires. Les dates de voyage et les marges se trouvent dans « Options ».

2 · Voyageurs

Ajoutez les personnes directement ou importez un fichier Excel. Le modèle téléchargeable précise les colonnes attendues : Prénom, Nom, Ville de départ ; dates individuelles facultatives.

3 · Recherche

Un clic recherche les allers et les retours de tous les participants. Les réglages permettent de choisir les transports et le nombre de correspondances.

4 · Excel

Choisissez « Un Excel pour tous » ou « Un Excel par personne ». Les cellules jaunes marquées « X » servent de cases universelles, y compris sur téléphone. Les fichiers individuels sont également disponibles séparément.

Réponses

Quand les fichiers complétés reviennent, ouvrez « Réponses » dans ce menu, importez les Excel et téléchargez le tableau pour préparer les réservations.

Précautions

Les horaires ne garantissent ni tarif, ni place, ni correspondance. Les participants restent dans le navigateur et dans les fichiers exportés ; pensez à sauvegarder avant de quitter.
